================================================================================
                    CRAVECART - FOOD ORDERING & DELIVERY SYSTEM
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
CraveCart is a modern, full-stack multi-user food ordering and on-demand delivery 
web application built using Python Flask, Vanilla CSS, SQLite (WAL mode), and 
Waitress WSGI. 

The platform supports 1,000+ simultaneous concurrent users and connects three 
distinct user roles into a single unified ecosystem:
  1. Customers: Browse restaurants, customize dishes, place orders, and track deliveries.
  2. Restaurant Partners: Manage incoming orders, kitchen queues, menus, items, and promos.
  3. Courier Drivers: Receive dispatch assignments, navigate deliveries, and track earnings.


2. THREE CORE USER PORTALS
--------------------------------------------------------------------------------

A. CUSTOMER EXPERIENCE
  - Restaurant Discovery: Filter by cuisine, dietary preferences (Veg, Vegan, Gluten-Free),
    ratings, delivery speed, and price level ($ to $$$$).
  - Search & Auto-Suggest: Instant real-time fuzzy search across restaurants and dishes.
  - Dish Customizer Modal: Select portion sizes (Small, Medium, Large, Multi-choice)
    and add-ons/modifiers with live price calculation and stock enforcement.
  - Smart Multi-Restaurant Cart: Prevents accidental multi-restaurant mixing with
    an interactive start-fresh prompt.
  - Promotional Engine: Apply promo discount codes (percentage, fixed discount, minimum
    spend requirements, and live countdown timers).
  - Secure Checkout: Address picker, driver tip selector, CravePoints loyalty reward
    calculation (10 pts per $1 spent), and multi-method payment gateway:
      * Debit / Credit Cards with 3D-Secure OTP verification simulation
      * UPI App Push & Dynamic QR Code countdown timer
      * Net Banking instant authorization
  - Live Real-Time Order Tracking: 7-stage order status progression 
    (Placed -> Confirmed -> Preparing -> Ready -> Picked Up -> On The Way -> Delivered)
    with animated courier marker movement along an SVG delivery route map.
  - Post-Order Review & 1-Click Reorder: Leave 1-5 star ratings and reviews that 
    dynamically recalculate restaurant average ratings.

B. RESTAURANT PARTNER PORTAL (/partner)
  - Live Kitchen Dashboard: Real-time order queue, total daily sales, average order value.
  - Kitchen Order Management: Advance order status from kitchen receipt to "Ready for Pickup".
  - Fleet Dispatch & Courier Allocation: Assign available online couriers to ready orders.
  - Menu & Category Management: Full CRUD for categories and menu items with image uploads,
    portion sizes, modifiers, dietary tags, and 86'd / In-Stock toggle switches.
  - Storefront Profile: Manage opening hours, delivery fees, minimum order amounts,
    cover banners, and logos.
  - Promotional Campaigns: Create and launch promo codes with custom expiry timers,
    extend live sales, toggle active status, or delete campaigns.
  - Analytics & Reports: View top-selling dishes, sales volume, and customer reviews.

C. COURIER DELIVERY DRIVER PORTAL (/courier)
  - Online / Offline Status Toggle: Instant shift check-in to receive delivery missions.
  - Active Delivery Queue: View pickup addresses, customer drop-off details, special notes.
  - Live Delivery Progression: Advance missions through "Picked Up" -> "On the Way" -> "Delivered".
  - Payout & Earnings Dashboard: View base delivery pay, customer tips, bonus earnings,
    and simulate instant cashouts.


3. TECHNICAL ARCHITECTURE & PERFORMANCE
--------------------------------------------------------------------------------
- Backend: Python 3.10+ / Flask Framework
- WSGI Web Server: Waitress Multi-Threaded Server (64 worker threads, 2000 connection limit)
- Database: SQLite with Write-Ahead Logging (WAL mode), busy timeout (30s), and memory cache
- Concurrency Tested: Benchmark verified for 1,000+ simultaneous concurrent sessions 
  (0 database locks, 100% request success rate, 320+ writes/sec)
- Frontend: Vanilla JavaScript (ES6+), Semantic HTML5, Custom CSS Design System
- Audio Synthesis: Web Audio API for tactile button clicks and payment success chimes

6. QUICK START GUIDE
--------------------------------------------------------------------------------
1. Install Dependencies:
   pip install -r requirements.txt

2. Run the Application:
   python app.py
   (or run: start_server.bat)

3. Open in Browser:
   http://localhost:5000 or http://127.0.0.1:5000

4. Run Full Test Suite:
   python test_app.py

5. Run 1000-User Concurrency Benchmark:
   python test_concurrency.py
